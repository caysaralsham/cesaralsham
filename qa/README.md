# الفحص والاختبارات

اختبارات آلية تتأكد أن كل شيء يعمل قبل أي نشر. **لا تتصل بأي بيانات حقيقية**: كل طلب خارج الجهاز (Firebase، Google…) يُلغى أثناء الاختبار.

## ماذا تفحص
- كل صفحات الموقع العربية والفرنسية وصفحة الباركود: تفتح بدون أخطاء، لها عنوان ووصف لمحركات البحث.
- الجوال: لا تتحرك الصفحة يميناً ويساراً.
- الأدوات (لوحة التحكم، الإعدادات، أدواتي، اللوغو، المرسم): مخفية عن غوغل، شريط التمرير على اليمين بالكمبيوتر.
- المرسم: الحفظ يرفض بدون اسم الزبون، والطباعة A4 تعمل.
- الأمان: لا أسرار في الملفات، ودوال الذكاء الاصطناعي محمية بتسجيل الدخول.

## التشغيل على جهازك
```powershell
cd qa
npm ci
npx playwright install chromium
npx playwright test
```

## الأخطاء المعروفة
الاختبارات المعلّمة بـ `test.fail` تصف خللاً موجوداً ينتظر الموافقة على إصلاحه. عند إصلاحه سينبّه الاختبار لإزالة العلامة.

التشغيل التلقائي على GitHub موجود في `.github/workflows/qa.yml`.

## صلاحيات Firestore
- `firestore/firestore.rules`: نسخة من القواعد المنشورة حالياً، للمرجع والاختبار فقط. **نشرها لا يتم من هنا.**
- `firestore/firestore.proposed.rules`: نسخة مقترحة تسد ثغرات عدّاد الزيارات.
- `firestore/storage.rules`: نسخة من قواعد Storage المنشورة، و`storage.proposed.rules` نسخة تمنع استبدال النسخ الاحتياطية.
- `npm run test:rules` يشغّل اختبارات Firestore وStorage على محاكي Firebase بمشروع وهمي (يحتاج Java 21).
